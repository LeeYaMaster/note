# 云云笔记

一个扁平风格的 Android 笔记应用，用 Jetpack Compose 实现。视觉上参考小米笔记的信息结构（列表、瀑布流、编辑页），但不用 Material 3 的默认主题、投影和色调。桌面名称是「云云笔记」，图标是一朵云。

## 环境

- Android Studio（当前稳定版即可）
- JDK 17 或以上
- Android SDK 35

## 打开并运行

1. 启动 Android Studio，选择 **Open**，打开本仓库根目录（包含 `settings.gradle.kts` 的那一层）。
2. 等待 Gradle Sync 完成。如果提示缺少 SDK，按提示安装 Android 35 平台。
3. 连接手机（开启 USB 调试）或启动一个 API 26 以上的模拟器。
4. 选择运行配置 `app`，点击 Run。

命令行构建：

```bash
export ANDROID_HOME="$HOME/Android/Sdk"   # 按本机 SDK 路径修改
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

## 可以试什么

- 首页右上角 **更多** 菜单里切换 **列表视图** 和 **瀑布流视图**。选择会记在本机，下次打开仍然保留。瀑布流里相邻卡片用不同的浅色。
- 长按一条笔记进入多选，再点其他笔记可继续勾选，顶栏 **删除** 会一起删掉。
- 点搜索可按标题和正文过滤。
- 点一条笔记进入编辑；右下角黄色 **+** 新建笔记。空白笔记返回时会丢弃。
- **清单**：插入可勾选的一行。点左边的圆角方框会填上绿色对勾，再点一次取消。文字字号和行高与正文相同，方框略小于文字高度。清单项之间大约多出半行。
- **图片 / 涂鸦**：点一下图片或涂鸦，图的正中会弹出操作（放大、缩小、删除、描述），带一个轻微的弹出动画。缩小后图片靠左。图片上下大约留 16dp，描述紧贴在图下。正文、清单和图片之间也是大约 16dp。
- **格式**：对当前这一行设置对齐（左对齐、居中、右对齐）和字体（系统默认、宋体风格、等宽代码、手写体）。
- 顶栏 **分享** 可以选择分享文字，或把笔记画成一张图片再分享。图片带浅色渐变和细线卡片，标题更大、离顶部更远。也可以删除当前笔记。

笔记写在应用私有的 SQLite 数据库里，图片和涂鸦写在应用内部存储。关掉应用、系统回收进程或重启手机之后，内容还在。卸载应用，或在系统设置里清除应用数据，会把数据库和图片一起删掉，这是 Android 的正常行为。第一次打开会放入几条示例笔记；删光之后不会再自动补回来。

## 目录

```
app/src/main/java/com/flatnotes
├── MainActivity.kt          窗口与入口
├── data/                    笔记模型、SQLite 与图片文件
├── domain/                  日期分组、时间文案
└── ui/
    ├── theme/               扁平配色（无 MaterialTheme）
    ├── components/          分割线、菜单、悬浮按钮
    ├── icons/               线性图标
    ├── notes/               列表与瀑布流
    └── editor/              编辑页
```

配色：背景白色，强调色 `#FFC107`，分割线 `#EEEEEE`，圆角 8dp。卡片和按钮都没有投影。
